# Reflection

## The most difficult concept
Navigating GitHub and Visual Studio Code was the hardest part for me. At first I could not tell whether I had installed Git Bash, so I used the Windows search bar to confirm it. I challenged myself to practise code in both platforms without moving to other platforms until I had a firm grasp of the concepts. I can now push my work to my GitHub repository using Git Bash, and when something does not work in Git, I can run a command in Git Bash to sort it out.

## What I would improve in my capstone
I would make my capstone more brief so that the marker can review the whole project without difficulty. In my later work I used a smaller diagram and tighter wording on each point to keep the document brief, and I will keep doing this.
