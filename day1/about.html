About QuickNotes

QuickNotes is a simple web app for jotting down ideas, reminders and to-dos without any fuss. It is built for anyone who wants to capture a thought in seconds and find it again later.

How to use QuickNotes

  1. Open the QuickNotes home page.
  2. Type your note into the text box.
  3. Click the Add Note button to store it.
  4. Review your saved notes in the list below.

Features

  • Fast note creation
  • Clean, distraction-free layout
  • Works in any modern browser
  • Keyboard shortcuts for common actions

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
Ctrl + D Delete the current note
